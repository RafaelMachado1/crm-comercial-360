# Fase 05 — Anotações pessoais

## O que vou estudar nesta fase

Nesta fase, vou estudar `useEffect`, `localStorage`, API fake e CRUD.

## O que preciso entender bem

- `useEffect` executa efeitos colaterais.
- O array de dependências controla quando o efeito roda.
- `localStorage` salva dados no navegador.
- `JSON.stringify` transforma objeto ou array em texto.
- `JSON.parse` transforma texto em objeto ou array novamente.
- API fake simula uma chamada assíncrona.
- CRUD representa criar, listar, atualizar e excluir.
- Arrays e objetos precisam continuar sendo atualizados de forma imutável.

## Como isso será aplicado no CRM

Nesta fase, vou fazer o CRM:

- carregar clientes salvos;
- salvar clientes no navegador;
- manter clientes após atualizar a página;
- simular busca de dados;
- editar clientes;
- excluir clientes;
- manter filtros funcionando com a lista atualizada.

## Observação

Esta fase é importante porque prepara o projeto para, no futuro, trocar dados locais por uma API real em Java Spring Boot.
