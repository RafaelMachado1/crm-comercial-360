# Fase 03 — Anotações pessoais

## O que vou estudar nesta fase

Nesta fase, vou estudar `useState`, eventos e renderização condicional.

## O que preciso entender bem

- State é uma memória interna do componente.
- Quando o state muda, o React renderiza a tela novamente.
- Eventos permitem que o usuário interaja com a aplicação.
- `onClick` é usado para cliques.
- `onChange` é usado para mudanças em campos.
- `onSubmit` é usado em formulários.
- Renderização condicional permite mostrar ou esconder elementos.
- Arrays e objetos não devem ser alterados diretamente.

## Como isso será aplicado no CRM

Nesta fase, vou adicionar interações reais no CRM:

- abrir e fechar sidebar;
- filtrar clientes por status;
- destacar cliente prioritário;
- abrir modal de detalhes do cliente;
- exibir estados de loading, erro e lista vazia.

## Observação

Esta fase é importante porque transforma a tela em uma aplicação interativa.
