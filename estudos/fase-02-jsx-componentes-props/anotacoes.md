# Fase 02 — Anotações pessoais

## O que vou estudar nesta fase

Nesta fase, vou estudar JSX, componentes funcionais, props, children e componentização.

## O que preciso entender bem

- JSX parece HTML, mas é JavaScript.
- Componentes são funções que retornam JSX.
- Props são dados enviados do componente pai para o filho.
- Children permite criar componentes mais flexíveis.
- Componentização ajuda a organizar o projeto.
- O `App.jsx` não deve concentrar toda a interface.

## Como isso será aplicado no CRM

A tela inicial será dividida em componentes reutilizáveis como:

- Header
- Sidebar
- PageTitle
- CardIndicador
- ClienteCard
- ProdutoCard
- Card
- Section

## Observação

Nesta fase, começo a transformar o CRM Comercial 360 em uma aplicação React mais organizada e próxima de um projeto real.
