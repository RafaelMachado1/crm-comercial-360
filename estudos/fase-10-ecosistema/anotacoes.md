# Fase 10 — Anotações pessoais

## Nome da fase

Bibliotecas de mercado e experiência profissional.

## Objetivo da fase

Adicionar ferramentas muito usadas no mercado para melhorar formulários, validação, requisições, cache, estado global, UI, gráficos, tabelas, datas e feedback visual.

## O que vou estudar

- React Hook Form
- Zod
- Axios
- TanStack Query
- Zustand
- Tailwind CSS
- Shadcn/UI ou componentes próprios
- Recharts
- TanStack Table
- date-fns
- Toast/feedback visual

## O que vou construir no projeto

- Substituir formulário manual por React Hook Form
- Validar cliente com Zod
- Criar camada de API com Axios
- Usar TanStack Query para buscar e cachear dados
- Usar Zustand para filtros globais ou preferências
- Criar dashboard com gráficos
- Criar tabela de clientes com ordenação e filtros
- Usar date-fns para lidar com datas
- Criar feedback visual com toast

## Observação importante

Cada biblioteca precisa resolver um problema real do projeto.

Não vamos instalar biblioteca apenas para enfeitar o package.json.

O objetivo é deixar o CRM mais profissional e mais forte para portfólio.
