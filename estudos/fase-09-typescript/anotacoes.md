# Fase 09 — Anotações pessoais

## Nome da fase

Migração para React com TypeScript.

## Objetivo da fase

Transformar o CRM Comercial 360 em uma versão profissional com tipagem, reduzindo erros e preparando o projeto para padrões de mercado.

## O que vou estudar

- TypeScript no React
- Props tipadas
- Tipos e interfaces
- Estado tipado
- Eventos tipados
- Formulário tipado
- Resposta de API tipada
- Evitar `any`
- Generics básicos

## O que vou construir no projeto

- Migrar o projeto de JavaScript para TypeScript
- Criar tipos principais do CRM
- Tipar componentes
- Tipar props
- Tipar hooks customizados
- Tipar formulários e eventos
- Tipar services
- Tipar utils
- Tipar contextos
- Corrigir erros do TypeScript

## Tipos principais que serão criados

- Customer
- Product
- Opportunity
- Activity
- Sale
- User

## Observação importante

Esta fase é estrutural e profissional.

O objetivo é migrar com cuidado, sem quebrar o projeto, entendendo cada tipo criado para conseguir explicar em entrevista.
