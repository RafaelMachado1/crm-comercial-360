# Fase 06 — Anotações pessoais

## O que vou estudar nesta fase

Nesta fase, vou estudar React Router, rotas, páginas e layout principal.

## O que preciso entender bem

- React Router permite criar navegação entre páginas.
- `BrowserRouter` habilita o sistema de rotas.
- `Routes` agrupa as rotas.
- `Route` define cada rota.
- `Link` cria navegação interna sem recarregar a página.
- `NavLink` permite destacar o link ativo.
- Layout principal evita repetição de Header e Sidebar.
- Páginas separam melhor as áreas do sistema.

## Como isso será aplicado no CRM

Nesta fase, vou organizar o CRM em páginas:

- Dashboard
- Clientes
- Produtos
- Atividades
- Vendas

Também vou criar uma página 404 para rotas inexistentes.

## Observação

Esta fase é importante porque transforma o projeto em uma aplicação com navegação real, mais próxima de um sistema profissional.
