# Fase 08 — Anotações pessoais

## Nome da fase

Hooks customizados e organização profissional.

## Objetivo da fase

Refatorar o CRM Comercial 360 para ficar mais parecido com código de mercado, reaproveitando lógicas e separando responsabilidades.

## O que vou estudar

- useRef
- useMemo
- useCallback
- Hooks customizados
- Quando otimizar e quando não otimizar
- Organização de pastas
- Services
- Utils
- Contexts
- Hooks
- Separação de responsabilidades

## O que vou construir no projeto

- Criar `useLocalStorage`
- Criar `useCustomers`
- Criar `useToggle`
- Mover chamadas para services
- Mover cálculos para utils
- Reorganizar pastas
- Evitar componentes gigantes

## Observação importante

Esta fase é mais estrutural do que visual.

O objetivo principal é deixar o código mais limpo, organizado e parecido com um projeto profissional de mercado.
